# Чек-лист проекта VB-AKF на C++

**Цель:** реализовать и исследовать вариационный байесовский адаптивный фильтр Калмана (VB-AKF) по статье Särkkä & Nummenmaa (2009), сравнить с классическим KF, затем проверить на данных нескольких температурных датчиков.

**Область алгоритма:** линейная модель, известная ковариация шума процесса `Q`, неизвестная изменяющаяся во времени **диагональная** ковариация шума измерений `R_k`. Это не специальная робастная модификация для выбросов.

**Правило:** переходить к следующему этапу только после выполнения критерия «Готово, когда». **Минимальная работающая версия** — после этапа 5. Многомерная модель и реальные данные — после неё.

## Этап 3. Обычный фильтр Калмана (`KalmanFilter`)

- [ ] Сделать класс с полями `m`, `P`, `Q`, `R`.
- [ ] Добавить конструктор с начальными параметрами `m0`, `P0`, `Q`, `R`.
- [ ] Реализовать прогноз: `m_pred = m`, `P_pred = P + Q`.
- [ ] Реализовать усиление: `K = P_pred / (P_pred + R)`.
- [ ] Реализовать коррекцию: `m = m_pred + K * (y - m_pred)`.
- [ ] Реализовать коррекцию ковариации: `P = (1 - K) * P_pred`.
- [ ] Сделать `update(measurement)` и геттеры для `m`, `P`.
- [ ] Проверить один шаг вручную на конкретных числах.
- [ ] Проверить работу на постоянном шуме и на скачках шума.
- [ ] Сохранить результат KF в CSV.

**Готово, когда:** KF выдаёт конечные значения, `P >= 0`, результат ручного расчёта совпадает с кодом, график строится.

## Этап 4. VB-AKF по алгоритму 1 статьи (`VBAKF`)

- [ ] Сделать класс с параметрами `m`, `P`, `alpha`, `beta`, `Q`, `rho`, `iterations`.
- [ ] Задать начальные параметры, например `m0=22`, `P0=1`, `alpha0=1`, `beta0=1`, `Q=0.01`, `rho=0.98`, `iterations=3`.
- [ ] Добавить проверки входных параметров: `Q >= 0`, `P0 >= 0`, `alpha0 > 0`, `beta0 > 0`, `0 < rho <= 1`, `iterations >= 1`.
- [ ] Реализовать прогноз состояния: `m_pred = m`; `P_pred = P + Q`.
- [ ] Реализовать прогноз шумовых параметров: `alpha_pred = rho * alpha`; `beta_pred = rho * beta`.
- [ ] Перед циклом установить `alpha_new = alpha_pred + 0.5`, `beta_iter = beta_pred`.
- [ ] Реализовать цикл из `N` итераций: `R_effective = beta_iter / alpha_new`.
- [ ] На каждой итерации пересчитывать `K`, `m_iter`, `P_iter` **от одного и того же** `m_pred`, `P_pred`.
- [ ] На каждой итерации обновлять `beta_iter = beta_pred + 0.5 * ((y - m_iter)^2 + P_iter)` — **от `beta_pred`, а не накоплением поверх прежнего `beta_iter`**.
- [ ] После последней итерации сохранить `m = m_iter`, `P = P_iter`, `alpha = alpha_new`, `beta = beta_iter`.
- [ ] Добавить `getEffectiveR() = beta / alpha` — эффективная ковариация, используемая в коррекции.
- [ ] Добавить `getPosteriorMeanR() = beta / (alpha - 1)` при `alpha > 1` — среднее дисперсии обратного гамма-распределения; различать эти две оценки.
- [ ] Проверить один шаг VB-AKF численно вручную, включая **две внутренние итерации**.
- [ ] Проверить на всех шагах: `alpha > 0`, `beta > 0`, `P >= 0`, отсутствие `NaN` и бесконечностей.

**Готово, когда:** VB-AKF выполняет все шаги формул алгоритма 1 и даёт воспроизводимые конечные результаты на искусственных данных.

- [ ] Определить смысл вектора `x_k`: например, температуры в `n` точках помещения, **без** восстановления непрерывного температурного поля.
- [ ] Определить смысл измерений `y_k` от `d` датчиков, записать размеры `A (n×n)`, `H (d×n)`, `Q (n×n)`, `P (n×n)`.
- [ ] Подключить Eigen через CMake для векторов, матриц и линейной алгебры.
- [ ] Начать с простой модели `A = I`, `H = I`, `n = d = 3` (затем масштабировать).
- [ ] Перенести KF на матричные формулы прогноза и коррекции.
- [ ] В VB-AKF хранить `alpha[i]`, `beta[i]` для каждого канала измерения.
- [ ] Строить `R_effective = diag(beta[i] / alpha[i])` — **диагональную** матрицу в рамках статьи.
- [ ] Обновлять `beta[i] = beta_pred[i] + 0.5 * ((y - H*m)[i]^2 + (H*P*H.transpose())[i,i])`.
- [ ] Вместо явного вычисления обратной матрицы использовать устойчивое решение линейной системы (например, `LDLT` в Eigen).
- [ ] Проверить симметрию ковариации, численную устойчивость и размерности матриц.
- [ ] Убедиться, что матричная реализация при `n=d=1` даёт тот же результат, что одномерная.
- [ ] Провести эксперименты с `d = 3`, `10`, `20` датчиками и сравнить время работы.
- [ ] По желанию выбрать модель с ненулевыми внедиагональными элементами `A` для связи температур соседних точек; **не** путать это с моделированием теплопереноса методом конечных элементов.

**Готово, когда:** многомерный VB-AKF работает, проверен на частном одномерном случае и на нескольких каналах измерений.
